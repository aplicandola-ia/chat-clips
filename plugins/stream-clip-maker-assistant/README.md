# Stream Clip Maker — ChatGPT plugin

Guides ChatGPT through Stream Clip Maker setup, Twitch and YouTube chat analysis, desktop/TUI workflows, local rendering, safe review and troubleshooting. It does not bypass creator permissions or publish content automatically.

Import the ZIP into a host that supports Agent Plugins packages, or use the private plugin saved to your ChatGPT account. Invoke it from the plugin picker / composer.
